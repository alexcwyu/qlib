Design decisions

Decision Rationale Tradeoff Evidence
Separate strategy decisions from execution frequency and account lifecycle. BaseExecutor handles bar-end metrics while subclasses implement execution. Execution realism remains constrained by the simulated exchange/data configuration. BaseExecutor.collect_data (L227) / SimulatorExecutor._collect_data (L590) / collect_data_loop (L52)
Track serialized artifacts through MLflow. Model outputs can be linked to experiments. Artifact persistence depends on the configured MLflow store. MLflowRecorder.save_objects (L407)

Strengths and limits

Strengths

  • ML training, RL policy adaptation and portfolio execution have separate source-backed boundaries. LGBModel.fit (L57) / SimulatorExecutor._collect_data (L590) / RLIntStrategy.generate_trade_decision (L292)

Limitations

  • Simulation and recorded artifacts do not establish live execution or profitable deployment. SimulatorExecutor._collect_data (L590) / MLflowRecorder.save_objects (L407)
